# Smart Brain

Face-detection demo: paste an image URL and the app draws a box around the face.
Face detection runs **in the browser** with [MediaPipe Face Detector](https://ai.google.dev/edge/mediapipe/solutions/vision/face_detector)
(self-hosted model + WASM, no API key). The Express API handles users/sessions (MongoDB)
and proxies images so the browser can read their pixels.

## Running locally

Requirements: Node 18+, Docker (for MongoDB).

```sh
# 1. MongoDB
docker run -d --name smart-brain-mongo -p 27017:27017 -v smart-brain-mongo-data:/data/db mongo:7

# 2. Config
cp .env.example .env          # then set SESSION_SECRET

# 3. Install
npm install

# 4. Run API (port 4000, auto-restarts) and React dev server (port 3000) in two terminals
npm run dev:server
npm run dev
```

Open http://localhost:3000 (the dev server proxies `/api` to port 4000).
For a production-style run, `npm run build` then `npm start` and open http://localhost:4000.

## Deploying to Render

`render.yaml` defines a single Node web service (Singapore, free plan) that builds the React app
and serves it plus the API from Express. MongoDB lives on MongoDB Atlas; set `MONGODB_URI`
in the Render Dashboard (`SESSION_SECRET` is generated by Render). Pushes to `master` auto-deploy.
